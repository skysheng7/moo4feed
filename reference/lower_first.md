# De-capitalize the First Letter of a String to Lower Case

Takes a character string and de-capitalizes the first letter, keeping
the rest of the string unchanged.

## Usage

``` r
lower_first(s)
```

## Arguments

- s:

  A character string to capitalize.

## Value

A character string with only the first letter de-capitalized.

## Examples

``` r
lower_first("Hello World")
#> [1] "hello World"
lower_first("R Programming")
#> [1] "r Programming"
```
