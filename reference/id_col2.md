# Get the name of the column recording animal ID

What's the name of the column recording animal ID? This should be a
Single string. (default: `"cow"`).

## Usage

``` r
id_col2()
```

## Value

A single character string stating the name of the column recording
animal ID (e.g., `"cow"`).

## Examples

``` r
id_col2()
#> [1] "cow"
```
