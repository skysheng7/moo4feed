# Get the name of the column recording transponder ID for each visit

What's the name of the column recording transponder ID for each visit?
This should be a single string. (default: `"transponder"`).

## Usage

``` r
trans_col2()
```

## Value

A single character string stating the name of the column recording
transponder ID (e.g., `"transponder"`).

## Examples

``` r
trans_col2()
#> [1] "tag_id"
```
