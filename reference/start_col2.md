# Get the name of the column recording the start time of an event

Name of the column recording the start time of an event, e.g.: start_col
= "start"

## Usage

``` r
start_col2()
```

## Value

A single character string indicating name of the column recording start
time of an event (e.g., `"start"`).

## Examples

``` r
start_col2()
#> [1] "start_time"
```
