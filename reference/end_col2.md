# Get the name of the column recording the end time of an event

Name of the column recording the end time of an event, e.g.:
`end_col = "end"`.

## Usage

``` r
end_col2()
```

## Value

A single character string indicating the name of the column recording
the end time of an event (e.g., `"end"`).

## Examples

``` r
end_col2()
#> [1] "end"
```
