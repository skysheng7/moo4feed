# Capitalize the First Letter of a String

Takes a character string and capitalizes the first letter, while making
all other characters lowercase.

## Usage

``` r
cap_first(s)
```

## Arguments

- s:

  A character string to capitalize.

## Value

A character string with only the first letter capitalized.

## Examples

``` r
cap_first("hello world")
#> [1] "Hello world"
cap_first("r programming")
#> [1] "R programming"
```
