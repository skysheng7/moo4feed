# Set the name of the intake column as global variable

Set the name of the intake column as global variable

## Usage

``` r
set_intake_col2(new_name = "intake")
```

## Arguments

- new_name:

  A single string indicating the new intake column name.

## Value

Called for its side-effects

## Examples

``` r
set_intake_col2("feed_intake")
intake_col2()
#> [1] "feed_intake"
```
